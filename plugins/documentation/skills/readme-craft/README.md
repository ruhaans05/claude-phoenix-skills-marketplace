# readme-craft

Writes or updates a README a newcomer can act on in minutes — what it is, why it exists,
install, a minimal working example, then deeper detail.

**Why it helps:** the README is the product's front door. A reader decides in the first screen
whether to keep going. This skill orders content most-important-first and keeps every command
correct.

**What it does:**
- Leads with what-it-is and the value, then copy-pasteable install, then a quickstart that
  works end to end.
- Writes for the newcomer audience: scannable, jargon explained, examples over prose.
- Keeps feature tables and version-specific commands synced with reality.

**Guardrail:** never documents unverified install steps or features, preserves an existing
README's voice when updating (changes what's wrong, doesn't rewrite wholesale).

Trigger phrases: "write a README", "improve the readme", "document the project".
